# Проект: "Структуры данных и управление памятью на C"

Этот проект направлен на создание различных структур данных и освоение методов работы с динамической памятью на языке C. Включает задачи, связанные с созданием и манипуляцией массивами, односвязными списками, стеками и динамическим выделением памяти, с акцентом на правильное тестирование и управление памятью.

## Quest 1: Структура дверей и сортировка

- **Описание**: Создана структура для дверей, включающая целочисленные поля `id` и `status` (0 - закрыта, 1 - открыта).
- Реализована сортировка массива структур дверей по `id` и обновление их статуса на "закрыта".
- Программа была собрана с использованием Makefile, исполнимая была помещена в папку `build` под именем `Quest_1`.

## Quest 2: Операции с односвязным списком дверей

- **Описание**: Разработана программа для работы с односвязным списком структур дверей. Реализованы функции:
  - Инициализация списка
  - Добавление новых дверей
  - Поиск двери по `id`
  - Удаление дверей
  - Уничтожение списка
- Написаны модульные тесты для функций добавления и удаления дверей, с проверкой правильного управления памятью.
- Программа протестирована с использованием `cppcheck` и собрана через Makefile, результат собран в исполнимый файл `Quest_2`.

## Quest 3: Реализация динамического стека

- **Описание**: Реализован динамический стек для хранения целых чисел, с функциями:
  - Инициализация стека
  - Добавление и извлечение элементов (`push` и `pop`)
  - Уничтожение стека
- Написаны модульные тесты для проверки работы операций `push` и `pop`.
- Программа протестирована с использованием `cppcheck` и собрана через Makefile, исполнимая была помещена в папку `build` под именем `Quest_3`.
